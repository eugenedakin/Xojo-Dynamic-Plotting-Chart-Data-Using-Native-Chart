# Xojo-Dynamic-Plotting-Chart-Data-Using-Native-Chart
This is a Xojo project that uses the native Chart control. This is commonly used for DAQ (Data Acquisition) that is used on Windows and the Raspberry Pi with electronics.

![](https://github.com/eugenedakin/Xojo-Dynamic-Plotting-Chart-Data-Using-Native-Chart/blob/main/SS1080Forum.gif)

The Xojo file (xojo_binary_project) was created in Windows 11 with Xojo 2026r2.1, and should work on all desktop systems, such as Raspberry Pi, and Mac.

The program dynamically shows the time that has elapsed with a random number generator used for creating data. The data is then shown to the user. 

When the button is green, then start the charting program, when red, data is being acquired, and pressing the red button will stop data being generated and displayed.
